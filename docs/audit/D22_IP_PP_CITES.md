## The defect

Batch 01b dropped "consequence gradient", "consequence-density field" and the governance-priority signal, which no entry in A carries. The IP file still cited these PPs for content they no longer carry, most visibly a "consequence gradient" at IP-9, IP-24, IP-38 and IP-59. Each IP Substrate Invariant, corollary, italic line and Irreducibility field that names one of the eight was read against the PP's current text and its IL parent.

## The rule applied

An IP entry crosses one IL entry with the PPs in its Applies-to line; each Substrate Invariant states what one PP requires of the process. A line is kept when the PP it names carries it (HOLDS). Otherwise it is restated to what the PP carries, or, when the PP places no constraint on the process, it is withdrawn.

Two further rules bind this correction:
- **Positions are kept.** Code realizing A cites IP lines by position (`IP-x:invN`, `IP-x:corN`). A withdrawn invariant is replaced by a marked line, `- **PP-n (no invariant):** …`, and a withdrawn corollary by a marked line under its own number. Nothing is renumbered, and the file keeps its line count.
- **Applies-to lines are ancestry and are unchanged.**
