## 1. Matrix Generative Operators & Relationship Types

Every transformation in the 4×4 matrix is generated by one of two conjugate operators:

- **Layer Fold Operator ($\Phi_r(L_{r-1})$) — Integration & Basis Compression:** The leftmost column (C-col: CC, LC, PC, IC) has no left cell. It takes the **completed layer directly above as its antecedent field** ($L_{r-1} = \{X_{r-1,C}, X_{r-1,L}, X_{r-1,P}, X_{r-1,I}\}$), integrating accumulated closure into the minimal conceptual basis of domain $r$:
  $$\mathbf{CC} = \Phi_C(W) \quad \text{(Extracted from antecedent body of work } W \text{)}$$
  $$\mathbf{LC} = \Phi_L(CC, CL, CP, CI)$$
  $$\mathbf{PC} = \Phi_P(LC, LL, LP, LI)$$
  $$\mathbf{IC} = \Phi_I(PC, PL, PP, PI) \quad \text{(Implementation Conceptualization of Physical Closure)}$$

- **Cell Crossing Operator ($\operatorname{Cross}(Left, Above)$) — Novel Differentiation Engine:** Non-C-column cells derive content horizontally from the left while applying domain context vertically from above:
  $$\text{Child} = \operatorname{Cross}(Left, Above) \quad \text{or} \quad Left \triangleleft_{Above}$$

The systemic generative rhythm alternates Basis Compression and Novel Differentiation:

$$\boxed{ \text{Work } W \xrightarrow{\Phi_C} \mathbf{CC} \xrightarrow{\operatorname{Cross}} \mathbf{C\text{-Layer}} \xrightarrow{\Phi_L} \mathbf{LC} \xrightarrow{\operatorname{Cross}} \mathbf{L\text{-Layer}} \xrightarrow{\Phi_P} \mathbf{PC} \xrightarrow{\operatorname{Cross}} \mathbf{P\text{-Layer}} \xrightarrow{\Phi_I} \mathbf{IC} \xrightarrow{\operatorname{Cross}} \mathbf{I\text{-Layer}} }$$

### Relationship Definitions

- **derives from** — horizontal (left parent). The child entry derives its content from the cell to its left.
- **applies to** — vertical (above parent). The child entry applies the domain context of the cell directly above it.
- **folds from** — layer fold (C-column parent field). The C-column entry integrates the minimal sufficient support set $S(X_{r,C}) \subseteq L_{r-1}$ of the completed layer above.
- **Non-Commutativity:** Crossing is directional ($\operatorname{Cross}(Left, Above) \neq \operatorname{Cross}(Above, Left)$). The left parent supplies derived content; the above parent supplies applied context.

## 2. Inviolable Topological Authorship Order

Because a Layer Fold $\Phi_r(L_{r-1})$ requires the completed layer state $L_{r-1}$ to exist, layer completion strictly precedes folding:

$$\boxed{\mathbf{CC} \to \mathbf{CL} \to \mathbf{CP} \to \mathbf{CI} \to \mathbf{LC} \to \mathbf{LL} \to \mathbf{LP} \to \mathbf{LI} \to \mathbf{PC} \to \mathbf{PL} \to \mathbf{PP} \to \mathbf{PI} \to \mathbf{IC} \to \mathbf{IL} \to \mathbf{IP} \to \mathbf{II}}$$

Among former pending cells, authorship strictly follows:

$$\boxed{\mathbf{PP} \longrightarrow \mathbf{PI} \longrightarrow \mathbf{IC} \longrightarrow \mathbf{IL} \longrightarrow \mathbf{IP} \longrightarrow \mathbf{II}}$$

## 3. Zero Pre-Filtering Mandate

No candidate pairs are filtered out or skipped based on lineage checks or shared ancestry assumptions.

> **Zero Pre-Filtering Mandate:** Every candidate pair $\operatorname{Cross}(Left, Above)$ must undergo direct qualitative collision analysis under System Foundations physics.

Every pair is classified into `IRREDUCIBLE`, `SUBSUMED`, or `BARREN`. Subsumption represents **structural derivational convergence**.

## 4. Operational Irreducibility Tests

### A. Cell Crossing Tests (Non-C-Column Cells)
Question: *"What irreducible constraint exists that NEITHER [left parent] alone NOR [above parent] alone makes — but that requires both simultaneously?"*

1. **Test 1 — Not produced by Left Parent alone:** Remove the above parent. Does the constraint still hold from the left parent only? If yes $\implies$ `BARREN`.
2. **Test 2 — Not produced by Above Parent alone:** Remove the left parent. Does the constraint still hold from the above parent only? If yes $\implies$ `BARREN`.
3. **Test 3 — Non-Redundancy:** Is this constraint already captured at this cell? If yes $\implies$ `SUBSUMED`. Actively unify derivation sources.

### B. Layer Fold Tests (C-Column Cells)
Question: *"What minimal conceptual basis in domain $r$ faithfully carries the completed work of $L_{r-1}$ forward?"*

1. **Fold Test 1 — Support Sufficiency:** Does $S(X_{r,C}) \subseteq L_{r-1}$ actually warrant $X_{r,C}$? (Prevents warrant inflation).
2. **Fold Test 2 — Conceptual Necessity:** Remove $X_{r,C}$. Can remaining Fold concepts carry the relevant structure in $S(X_{r,C})$? If yes $\implies$ redundant.
3. **Fold Test 3 — Minimal Support:** Can any element be removed from $S(X_{r,C})$ without losing warrant for $X_{r,C}$? If yes $\implies$ support set is not minimal.
4. **Fold Test 4 — Antecedent Input Coverage:** Has every materially relevant element $a \in L_{r-1}$ been accounted for in the Fold receipt? (Prevents ancestral erasure).
